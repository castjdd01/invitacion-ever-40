# Invitación galáctica de Ever Adilson

Sitio estático en HTML, CSS y JavaScript vanilla, diseñado primero para móvil. No usa backend, cuentas, formularios, analítica ni servicios de pago.

## Enlaces

- Invitación: https://castjdd01.github.io/invitacion-ever-40/
- Repositorio: https://github.com/castjdd01/invitacion-ever-40

GitHub Pages publica desde la rama main y la carpeta raíz. Los cambios enviados a main se despliegan desde GitHub Pages.

## Experiencia

La invitación inicia con Iniciar misión. Luego puedes seguir la historia o saltar directamente a Ver fecha y lugar. El botón de Olivia Bistro abre Google Maps con una búsqueda por nombre y dirección, sin coordenadas inventadas.

La invitación intenta reproducir automáticamente `assets/Star Wars Main Theme (Full).mp3` al abrir. Algunos navegadores móviles bloquean el audio automático; en ese caso, el botón de música o el primer toque en Iniciar misión lo activan. El botón también permite silenciar y volver a reproducir la pista. En pantallas de 380 px o menos, las tarjetas de fecha y hora se apilan para mantener los datos legibles.

## Cambiar datos

Edita el nombre, la edad, la fecha, la hora y la dirección en index.html. Actualiza también la descripción Open Graph y el arte de assets/og-invitacion.png si cambian los datos. La miniatura social usa URLs HTTPS absolutas para GitHub Pages.
